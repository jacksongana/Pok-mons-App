Projet : Pokémons App
Type : Application mobile (Projet personnel)
Technologies : React.js, Expo Go, Node.js (serveur local), API PokéAPI

Description :
J’ai développé une application mobile Pokémon avec React.js et Expo Go, connectée à un serveur local Node.js.
Cette application permet aux utilisateurs de consulter tous les Pokémons, leurs caractéristiques, et de les classer par catégories et puissances.

Fonctionnalités principales :
📱 Interface mobile fluide et intuitive via Expo Go

🔌 Connexion à une API Pokémon (PokéAPI) pour récupérer toutes les données

📋 Liste complète des Pokémons avec affichage de :

Nom

Type(s)

Statistiques : puissance, agilité, etc.

Icônes et images officielles

🏷️ Tri par catégorie (type de Pokémon)

💪 Classement par puissance (par exemple : agilité, attaque, défense...)

🌐 Serveur Node.js local pour le développement et le test de l’application
